02viz

Geospatial Visualization Studio — multi-engine chart, diagram, and label studio • v0.14.0

1. Overview

02viz is a QGIS plugin that turns the GIS environment into a full data visualisation studio. It provides a single dock with three tabs—Charts, Map Diagrams, and Labels—all sharing a common layer and data selector. It supports four rendering engines (both zero-dependency offline JS engines and optional Python engines) for making interactive, publishable charts from QGIS layers or external tabular data. The plugin runs entirely offline with no accounts, no network, and no mandatory external Python dependencies.

The plugin ships with bundled, vendored copies of Apache ECharts, Plotly.js, Vega, and Vega-Lite in web/. The chart-to-map selection bridge uses the browser's document.title as a click-event transport channel, avoiding the need for QWebChannel in any QtWebKit build.

4. Charts Tab

4.1 Themes and Palettes

Four Themes, Eight Palettes, Custom Editor

Themes: Studio Light (default, #fbfbfd), Ink Dark (#131c21), Soft Pastel (#ffffff), Bold Print (#ffffff / dark text).

Palettes: Vivid, Colorblind safe (8-colour), Viridis, Sunset, Ocean, Earth, Berry, Grayscale print.

Custom palette editor: Inline colour swatch editor with click-to-change and +/- buttons to add/remove colours (up to 16). Switches to "Custom..." mode.

4.2 Chart-to-Map Selection Bridge

Title-Based Click Transport

Chart pages encode clicked feature IDs as document.title = "o2viz-select:<id,id,...>:<seq>" via a helper __o2vizSelect() function defined in the engine base BRIDGE_JS. The dock listens to the webview's titleChanged signal (API-consistent across QtWebKit and QtWebEngine) and forwards it to a SelectionBridge, which selects those features on the QGIS canvas. Map-to-chart cross-filtering pushes __o2vizHighlight(ids) to the page to dim non-selected items.

4.3 Smart Chart Suggestions

Offline Field Analysis

The "Suggest a chart" button analyses the selected layer's field types (numeric/categorical/identifier via fields.py), recommends the most suitable chart, configures all controls, and renders the result. The algorithm runs entirely offline with no API calls.

5. Map Diagrams Tab

Native QGIS Per-Feature Diagrams

Four diagram types via QgsDiagramRenderer: Pie (QgsPieDiagram), Bar (QgsHistogramDiagram), Stacked bar (QgsStackedBarDiagram, QGIS 3.14+), and Text (QgsTextDiagram).

Key features: diagram size in millimetres (3–60 mm, default 14 mm), placement by geometry type (AroundPoint / Line / OverPoint), palette cycling across fields, and four normalisation modes:

ModeExpressionUse Case
NoneRaw valuesSame-scale fields
Min-max (0–1)(value − min) / (max − min)Different ranges
Z-score(value − mean) / stdStatistical comparison (warns for pies: negative angles impossible)

Normalisation expressions are baked into the diagram's classified expression—no new columns are written to the source data.

6. Labels Tab

Expression-Driven, Formatted Feature Labels

Four presets: Clean (subtle halo, 0.6 mm), Strong halo (1.2 mm), Bold, Plain. Formatting controls: primary field, optional second-row field (joined with char(10) newline), decimal places (−1–6, using round() or format_number()), thousands separator (format_number()), prefix/suffix (concat()), case conversion (none / upper / lower / title), word wrap (wordwrap() with configurable character limit). Advanced expression mode: freeform text field for raw QGIS expressions; overrides all other formatting controls; validated before application. Live preview shows the exact expression and the first feature's evaluated value.

7. One-Click Explore Dashboard

Full Layer Analysis in One Click

The "Explore layer" button builds a single-page interactive ECharts dashboard. Tiles (toggleable via a Tile Picker): KPI cards (row count, field count, numeric/categorical field counts, completeness %), field summary table (name, type badge, missing %, distinct count, numeric min…mean…max, categorical top value), bar charts for categorical fields (up to 4), histograms for numeric fields (up to 6, 14 bins), normalised box plots (all numeric fields on a 0–1 axis for cross-scale comparison), Pearson correlation matrix (diverging colour), strongest-correlation scatter plot with trend line (sampled to 3,000 points), and text insights (strongest correlations, field ranges, skewness with log-transform hints, outliers, near-constant fields, mostly-null fields). Identifier fields (matching patterns like fid, id, gid, uuid, objectid, *_id) are excluded.

8. Animation (Play Axis)

Temporal and Sequence Animation

Available for Bar, Line, Area, Scatter, Bubble, and Pie charts when an "Animate by" field (typically year or sequence) is selected. Frames are built entirely in pure Python (transform.build_frames, union_categories, align_values): rows are partitioned by the animate field (numeric-aware sort), each frame uses the same chart-type transformer, stable axes guarantee each category keeps its position and colour across frames, and global numeric ranges are fixed so axes do not rescale. Bubble sizes are globally scaled once so values map to the same radius throughout. Playback speed: Slow (1600 ms/frame), Medium (900 ms), Fast (450 ms). ECharts renders as timeline with autoPlay and loop; Plotly renders as frames with slider and play/pause buttons.

9. Reference Overlays

Statistical Reference Lines and Bands

Available for Bar, Line, Area, Scatter, and Bubble charts. Computed entirely in pure Python: Mean (dashed line at mean), Median (dotted line at median), ±1σ band (shaded region around mean), IQR band (Q1–Q3 shaded region), Target value (emphasis line at any user-entered value). Rendered identically across engines: ECharts via markLines/markAreas, Plotly via shapes+annotations, Vega-Lite via rule/rect layers, matplotlib via axhline/axhspan. Hidden during animation (the play axis tells its own story).

11. Workflow Guide

  1. Click the 02viz toolbar icon to toggle the dock.
  2. Data: Select a vector layer from the shared layer combo.
  3. Charts: Choose an engine and chart type. Bind fields (X, Y, Group, Value). Set aggregation, bins, and sort. Click Render chart. Click chart elements to select features on the canvas. Export as self-contained HTML, SVG, PNG, or PDF.
  4. Diagrams: Check numeric fields, choose diagram type, set size, pick normalisation mode. Click Apply to layer. Diagrams render on the map canvas.
  5. Labels: Choose fields, configure formatting (decimals, separator, case, wrap). Click Apply to layer. Labels render on the map canvas.
  6. Explore: Click the "Explore layer" button for a one-click full dashboard. Use the Tile Picker to toggle individual dashboard tiles.
  7. Animation: Select an "Animate by" field (e.g., year). The chart renders with time controls. Set playback speed.
  8. External data: Load CSV, XLSX, ODS, GPKG, or DBF via the file loader; it appears in the layer combo like any vector layer.

12. Technical Notes

  • Pure-Python statistics (zero dependencies): All aggregation, histogram binning, Pearson correlation, KDE (Silverman bandwidth), boxplot stats (five-number summary with linear interpolation), quantile, skewness, outlier detection (Tukey 1.5×IQR), and min-max normalisation are implemented in pure Python with no numpy/pandas dependency.
  • Data shaping: Group-by, pivot (category × series), heatmap matrix, treemap/sunburst nested hierarchies, Top-N with "Other" collapse, frame-building for animation, bubble radius sqrt-scaling, and least-squares trend line endpoints.
  • Engine isolation: Every engine exposes only build_html(spec) → str. They never touch Qt. Testable in pure Python. Usable for batch export.
  • WebView fallback chain: QtWebEngine (Chromium) → QtWebKit (legacy QWebView) → system browser. When Plotly/Vega-Lite are used on a WebKit-only QGIS build, a plain HTML/CSS explainer page shows why the panel is blank and offers solutions.
  • Dock styling: Explicitly locked light theme with white backgrounds, dark text, and teal selection to render consistently across Qt5 (light palette) and Qt6 (dark palette).
  • Chart presets: Version-controlled JSON in QSettings (up to 50 presets, schema v1). Validated on load; unavailable fields cleared with a report.
  • SmartModeler bridge: v0.14.0 adds a narrow public method smartmodeler_suggest_chart(layer_id) for integration with SmartModeler GIS.
  • QGIS compatibility: 3.28 through 4.99. Zero external Python dependencies. Bundled JS libraries: ECharts, Plotly.js, Vega, Vega-Lite.
